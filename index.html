What is Raspberry Pi?

Single-Board Computer

Raspberry Pi is a small, affordable single-board computer developed to help people learn programming and electronics. Despite its compact size, it can perform many tasks such as web browsing, coding, robotics, AI projects, and IoT applications.

Students and hobbyists widely use it because it is easy to set up and consumes very little power.

Low power consumption (5V) ARM-based processor architecture Widely used for Python, Linux & IoT

Q7

Why is a GPU faster than a CPU?

Computer Architecture

A CPU has a few powerful cores designed for low-latency execution of many diverse, sequential tasks, with large caches and complex branch prediction logic.

In contrast, a GPU has thousands of smaller, efficient cores designed to perform many similar mathematical calculations concurrently. This high-throughput parallel processing architecture makes GPUs dramatically faster for matrix multiplications, 3D graphics rendering, AI model training/inference, and scientific computing.

Metric CPU (Central Processing Unit) GPU (Graphics Processing Unit)
Core Architecture Few powerful cores (typically 4–32 cores) Thousands of lightweight cores (1,000–16,000+)
Optimization Goal Low Latency for sequential execution High Throughput for massively parallel computations
Best Suited For Operating systems, general logic, serial code Matrix operations, Deep Learning, Image rendering
Q8

Define CPU, GPU and TPU

Hardware Processors
CPU
Central Processing Unit

The primary processor in a computer that executes general-purpose instructions and coordinates all hardware subsystems using the fetch-decode-execute cycle.

GPU
Graphics Processing Unit

A specialized parallel processor designed to rapidly manipulate computer graphics, image processing, and highly parallel AI workloads.

TPU
Tensor Processing Unit

An Application-Specific Integrated Circuit (ASIC) custom-developed by Google specifically engineered to accelerate tensor operations in neural network and machine learning workloads.

Q11

Which company made your laptop's CPU?

Hardware Identification

The answer depends on your specific laptop. Common CPU manufacturers powering modern computers are:

Intel (Core / Ultra) AMD (Ryzen) Apple (M-Series Silicon) Qualcomm (Snapdragon X Elite)
How to check on a Windows Laptop:
  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Click on the Performance tab on the left sidebar.
  3. Select CPU — the top-right corner displays your processor brand and model (e.g. Intel Core i5 / AMD Ryzen 7).
  4. Alternatively, press Win + R, type msinfo32, and check the Processor line in System Information.
